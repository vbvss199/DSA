CAP theorem explains the trade-off in distributed databases. It says that a distributed system can provide only two out of these three guarantees at the same time:
Consistency,  Availability,  Partition Tolerance P

Consistency : every read gets the most recent data 
user updates the profiles 
Database A writes the profile name 

Immediately reading from the database b should omit the recent profile name 

Availability:Every request receives a response, even if the response may not have the latest data.
Database replica is temporarily unavailable

User requests data

System still returns a response
(possibly older data)
